## ⚙️ 特性

### 核心玩法（灵感来自 Hypixel TowerWars）
- 策略性放置塔以防守你的赛道（8 种塔）
  - 复刻塔的功能与技能（狙击/机枪/溅射/减速/点燃/眩晕/激光/逼退/增益）
- 派怪进攻敌方赛道并偷取生命（29 种怪）
  - 自定义怪物技能（治疗/吸收/分裂/重生/传送/减速/眩晕/失明/闪避…）
  - 收入进化：基础怪随收入自动进化为高级形态
  - 召唤进化：专精一路怪获得属性加成
- 经济系统（收入与金币）与复刻的侧边栏
- 带倒计时与 BossBar 的排队系统
- 平衡性尽可能贴近原版

### 🎮 玩法模式（本版新增）
| 模式 | 玩法 |
|---|---|
| **经典** | 每人一条赛道，放塔 + 送怪（原版玩法） |
| **围攻 1vN** | 1 名防守者（只能放塔守赛道）vs N 名进攻者（只能送怪），限时 10 分钟攻防战 |
| **合作** | 全体玩家同队各守各的赛道，对抗 20 波系统刷怪（PvE，后期出 Boss） |

### 🛠 管理工具（本版新增）
- **单人测试模式**：`/towerwars test <竞技场>` 无需其他玩家、无需启用竞技场，
  直接开局验证路径/塔位/防守；编辑器菜单内置"测试竞技场"按钮
- **GUI 全面美化**：放塔/召唤/升级/统计/编辑器 5 个菜单迁移至 **InvUI 1.49**
  （Adventure 原生渲染，已打包进插件 jar，服务器无需额外安装）
- **交互引导**：所有游戏物品、菜单按钮、加入牌均带"怎么用"提示
- 修复原版遗留崩溃：主循环并发修改、关服崩溃、调试木棍汉化失效等

### 附加特性
- 基于 SQLite 的复杂统计追踪（6 项战绩 + 6 个 TOP-10 排行榜）
- 可交互的大厅加入牌
- 自定义 GUI 竞技场配置器
- 权限系统
- 高度可定制（塔/怪/竞技场全部 YAML 配置）

## 🗺️ 环境搭建（推荐）

竞技场需要一片**平坦的虚空世界**来搭建赛道（避免地形干扰），推荐配合以下插件使用：

| 插件 | 版本 | 用途 |
|---|---|---|
| **Multiverse-Core** | 5.7.3 | 多世界核心：创建与管理竞技场虚空世界 |
| **VoidWorldGenerator** | 1.3.13 | 虚空世界生成器：生成平坦虚空地形 |

**服务器配置教程（先看再搭）：**

- 📖 文字教程：[**Minecraft Wiki：架设 Java 版服务器**](https://zh.minecraft.wiki/w/Tutorial:%E6%9E%B6%E8%AE%BEJava%E7%89%88%E6%9C%8D%E5%8A%A1%E5%99%A8)
  —— 教程中的服务端请选用 **Purpur 端**（下载地址见下方注意事项）
- 🎬 视频教程：[**苏打baka：保姆级教程！教你开设MC服务器，自己当服主权限不求人！**](https://www.bilibili.com/video/BV1rq4y117uA/?share_source=copy_web&vd_source=9ec889a29de835e0e9e50e1b8acedc77)

**生成竞技场虚空世界：**

1. 把两个插件的 jar 放入 `plugins/` 目录并重启服务端
2. 执行以下命令创建虚空世界（控制台或游戏内，需 op）：

   ```
   /mv create <世界名> NORMAL -g voidworld
   ```

   > 例：`/mv create tw_arena NORMAL -g voidworld`
3. 在 TowerWars 编辑器中把竞技场世界设为该世界名：
   `/towerwars arena configure <竞技场>` → 点击 **"世界名"** 物品（橡木告示牌）
   → 竞技场世界即切换为你所在的虚空世界
4. 继续配置出生点 / 边界 / 路径（详见[配置指南](docs/configuration.md)），
   然后点"测试竞技场"验证

> 📖 **服务器配置教程**：[Minecraft Wiki：架设 Java 版服务器](https://zh.minecraft.wiki/w/Tutorial:%E6%9E%B6%E8%AE%BEJava%E7%89%88%E6%9C%8D%E5%8A%A1%E5%99%A8)
> —— 服务端请选用 **Purpur 端**：[下载（1.21.4）](https://purpurmc.org/download/purpur/1.21.4)，
> ⚠️ 请选择 **1.21.4 或更高版本**（插件 API 版本要求）。
>
> 🎬 **视频教程**：[苏打baka：保姆级教程！教你开设MC服务器，自己当服主权限不求人！【我的世界】](https://www.bilibili.com/video/BV1rq4y117uA/?share_source=copy_web&vd_source=9ec889a29de835e0e9e50e1b8acedc77)
>
> 不安装也能用：竞技场世界也可以是服务器内任何已加载的普通世界，
> 但虚空世界能保证路径与塔位完全由你设计，不受地形影响。

## 🛠️ 构建

- **JDK 21+**（Gradle 守护进程必须使用 ≤21 的 JDK——系统默认 JDK 26 会导致
  构建脚本编译失败；`gradle.properties` 已配置本机 JDK 21 路径，其他机器
  请按注释自行调整）
- 构建产物：`build/libs/TowerWarsReborn-1.0-SNAPSHOT.jar`（fat-jar，内含 InvUI）

# 配置指南

本指南介绍竞技场管理命令、加入牌设置、配置文件、权限、玩法模式与一般设置。

---

## 🏟 竞技场管理

### `/towerwars arena list`
- **说明**：查看所有竞技场及其状态（启用/禁用）与是否空闲可加入。
- **权限**：`towerwars.list` _（默认：所有人）_

### `/towerwars arena configure <竞技场名>`
- **说明**：
  - 若 `<竞技场名>` 不存在，则新建一个竞技场。
  - 若已存在，则打开游戏内竞技场配置器，编辑路径、出生点、塔位、生命等。
- **权限**：`towerwars.configure` _（默认：op）_
- **文末有完整的竞技场配置说明！**

### 编辑完成后的验证
- 编辑器菜单中的**"测试竞技场"按钮**（红石火把）：保存配置并立即**单人开局**
  （无需启用竞技场），验证路径/塔位/防守后再开放给玩家。
- 也可使用 `/towerwars test <竞技场名>`（见下文"单人测试模式"）。

## 🎮 玩法模式

模式由加入命令选择，**无独立配置文件**：

| 模式 | 命令 | 规则 |
|---|---|---|
| 经典 | `/towerwars join <竞技场>` | 每人一条赛道，放塔 + 送怪 |
| 围攻 | `/towerwars join <竞技场> siege` | 第 1 个加入者 = 防守者，其余 = 进攻者 |
| 合作 | `/towerwars join <竞技场> coop` | 同队守 20 波系统刷怪 |

- 同一竞技场同时只能进行一个游戏（含排队）。
- 加入牌默认创建经典模式队列。
- 模式数值（围攻限时 600 秒、20 波、波次间隔/数量公式）定义在
  `Game.java` 顶部常量中，如需调整请改源码后重新编译。

## 🔖 加入牌

1. 放置一块告示牌，**第一行**精确写入：`[towerwars]`（大小写不敏感）
2. 在**第二行**写入你想关联的竞技场精确名字。
3. 插件会自动配置其余内容：第 2 行显示"右键点击加入"提示，第 4 行实时显示
   已禁用 / 已满 / 排队人数。

- **放置牌权限**：`towerwars.placesign` _（默认：op）_
- **使用牌权限**：`towerwars.usesign` _（默认：所有人）_

---

## 🧪 单人测试模式

```
/towerwars test <竞技场名>
```

- **权限**：`towerwars.test` _（默认：op）_
- 单人立即开局，**无需启用竞技场**（配置必须完整）
- 怪从自己的赛道出发，用于验证路径、防守与漏怪扣命
- `/towerwars leave` 结束测试；配合 `/towerwars increaseincome <数量>`
  （`towerwars.debug`）可快速测试高级塔/怪

## 🛠 配置文件

所有配置文件位于 `plugins/TowerWarsReborn/`。

| 文件                 | 用途                                                                                                                                                |
|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| `config.yml`         | 启用/禁用竞技场；统计追踪开关。**注意：** 未列在 `arenas` 列表里的竞技场**不会**被加载，即使它们的独立文件存在。 |
| `mobConfig.yml`      | 平衡各类怪物：价格、送怪收入、速度、生命、特殊能力。                                                                                                 |
| `towerConfig.yml`    | 平衡各类塔：价格、范围、溅射半径、攻速、特殊行为。                                                                                                   |
| `<竞技场名>.yml`     | 每个竞技场的专属设置（路径、出生点、塔位）。_请勿手动修改。_                                                                                       |
| `managedSigns.yml`   | 受管加入牌注册表。_除非迁移或排障，否则不要动它。_                                                                                                 |

| 权限                   | 默认      | 说明                                                                      |
|------------------------|-----------|---------------------------------------------------------------------------|
| `towerwars.list`       | 所有人    | 查看可用竞技场及其启用/禁用、空闲/进行中状态。                            |
| `towerwars.configure`  | op        | 使用 `/towerwars arena configure <竞技场名>`。                             |
| `towerwars.placesign`  | op        | 放置 `[towerwars]` 竞技场加入牌。                                          |
| `towerwars.usesign`    | 所有人    | 点击已配置的加入牌加入竞技场。                                              |

| `towerwars.forcestart` | op        | 在倒计时结束前使用 `/towerwars forcestart` 强制开局。                       |
| `towerwars.test`       | op        | `/towerwars test <竞技场名>` 单人测试模式（无需启用竞技场即可验证配置）。    |
| `towerwars.debug`      | 无        | `/towerwars debug` 与 `/towerwars increaseincome <数量>`                   |

## 📝 竞技场配置说明

使用 `/towerwars arena configure <竞技场名>` 创建或编辑竞技场前，请仔细阅读以下说明。

### 竞技场配置文件
这些文件大多是插件解析的原始数据。不了解插件内部机制就修改它，非常不建议。

### 竞技场世界
竞技场世界是所有赛道所在的世界。你无法在任何其他世界里设置轨道出生点、边界或路径点。
必须首先设置它，因为它是轨道出生点的基础。

### 轨道出生点
- 每个轨道出生点对应一条赛道。赛道有自己的边界与路径点。
- 所有赛道的边界、路径配置和**朝向**都相同，但其他方面可以不同。
- 轨道出生点是每条赛道的"锚点"。它是唯一以绝对坐标保存的位置，所有边界与路径点都是向量，相对各自的轨道出生点偏移。这样便于整体移动和配置赛道。
- 至少设置 2 个、至多 6 个轨道出生点。
- 围攻模式只需 1 个出生点（防守者赛道），其余玩家作为进攻者无需赛道。

### 轨道边界
- 轨道边界是赛道的二维"角点"。Y 坐标会被忽略，因此赛道不能上下堆叠。
- 塔只能放置在轨道边界**内部**。
- 边界必须构成矩形。
- 只需为一条赛道设置边界，其他赛道会自动同步。路径点同理。

### 路径
- 路径由告诉怪物往哪走的路径点组成。
- 怪物只能沿坐标轴平行方向直线移动。
- 怪物也可以上下移动，但只能走台阶（slab）！
- 一条赛道可以有多条路径（但至少一条）。

### 路径点
- 路径点必须按正确顺序设置（起点到终点，分别由白色与黑色烟雾粒子标记）。
- 相邻两个路径点之间最多只能在一个坐标方向上不同。
- 每条路径至少包含 3 个路径点。
- **终点就是路径的最后一个路径点**——没有独立的终点配置。

### 其他
- 塔放置方块定义了玩家可以放塔的方块类型。
- 大厅位置（如已设置）会在玩家加入队列时把玩家传送到"大厅"。
- 启用竞技场时会执行一些完整性校验，但**不应依赖**它们！
- 配置完成后建议先用"测试竞技场"按钮或 `/towerwars test` 验证，再启用开放。

# 使用说明

## 🎛️ 基础命令

| 命令 | 说明 |
|---|---|
| `/towerwars join <竞技场名> [模式]` | 加入指定竞技场。可选模式：`classic` / `siege` / `coop`（缺省 classic）。**或者**点击已配置的"加入牌"自动进入（经典模式） |
| `/towerwars leave` | 退出当前竞技场、等待大厅，或围攻模式中弃权 |
| `/towerwars arena list` | 查看所有可用竞技场（启用/禁用、空闲/进行中） |
| `/towerwars test <竞技场名>` | **单人测试模式**（需要 `towerwars.test`）：无需排队立即单人开局，用于验证竞技场 |
| `/towerwars help` | 显示命令用法 |
| `/towerwars forcestart` | 在倒计时结束前强制开局（`towerwars.forcestart`） |

**排障提示：** 如果某个命令不生效，请确认权限配置正确（联系服主）。

## 🎮 玩法模式

### 经典模式（CLASSIC）— 默认
`/towerwars join <竞技场>`
- 每人一条赛道，**既能放塔又能送怪**
- 送怪偷取对方生命，把所有人生命打到 0 获胜（2~6 人）

### 围攻模式（SIEGE）— 1 守 vs N 攻
`/towerwars join <竞技场> siege`
- **第 1 个加入队列的人 = 防守者**：拥有赛道，只能放塔/升级塔
- **其余人 = 进攻者**：没有赛道，只能送怪——所有怪都打向防守者的赛道
- 进攻者同样拥有收入进化与召唤加成（各自独立）
- **胜负**：
  - 防守者生命归零 → **进攻方全体胜利**
  - 限时 10 分钟守住 → **防守方胜利**
- 进攻者侧边栏显示围攻倒计时与防守者生命；`/towerwars leave` 可中途弃权

### 合作模式（CO_OP）— 同队守波次
`/towerwars join <竞技场> coop`
- 全体玩家同队，各守各的赛道
- 系统每 20 秒刷一波怪（第一波 10 秒后到达），共 **20 波**：
  - 波次越高怪越多（2 + 波次/3 只/赛道）
  - 第 8 波起出现高级怪，第 15 波起概率出现 Boss（幽灵/死亡骑士）
  - 波次随机攻击 1~2 条存活赛道
- **胜负**：打完 20 波且仍有赛道存活 = 全员胜利；全员淘汰 = 失败
- 漏怪只扣 1 心（同队无偷命）；击杀怪物获得金币/收入

## 🚪 大厅命令与操作

- **离开大厅**：使用 `/towerwars leave`，**或**点击背包里的"离开"时钟（lore 有提示）
- **查看你的统计**：点击背包里的"统计"告示牌（若统计追踪已启用）
- **强制开局**：`/towerwars forcestart`（需要 `towerwars.forcestart` 权限）

## 🧪 单人测试模式

管理员配置完竞技场后，无需其他玩家即可验证：

```
/towerwars test <竞技场名>
```

- **无需启用竞技场**即可测试（配置必须完整：世界/出生点/边界/路径/放塔方块）
- 送出的怪会从**你自己的赛道**出发——用于验证路径走向、塔的防守与漏怪扣命
- 可用 `/towerwars increaseincome <数量>`（`towerwars.debug`）快速加收入测试高级塔/怪
- `/towerwars leave` 结束测试
- **或者**：竞技场编辑器中点击"测试竞技场"按钮（红石火把），自动保存配置并开局

## 🎮 核心玩法

### 🏗️ 塔

- **放置塔**
  - 手持**"放置塔"**物品（盔甲架）右键：只能放在竞技场配置的**放塔方块**上
    （默认草方块，准星指向时冒粒子提示）且必须在**轨道边界内**
  - 右键弹出 8 座塔的菜单：等级 1/2/3 + 专精二选一（普通塔）；
    价格 < 收入×5 才解锁，点击放置
- **打开 / 升级塔**
  - 手持"放置塔"物品右键**已有塔的塔身** → 打开塔菜单（升级/出售/替换/专精/
    显示射程/统计）
  - 手持**"升级塔"**物品（经验瓶）右键对准塔身 → 距离升级，金币自动扣除
- **围攻模式防守者**：只有放塔/升级塔物品；**进攻者**：只有召唤怪物品
  （试图放塔会收到提示）

### 👾 怪物

- **送怪**：手持**"召唤怪"**物品（下界之星）右键 → 打开召唤菜单 → 点击送出
- **怪物进化**：基础怪随收入自动进化；同种怪送得越多属性越强（上限 300 次）
- **自定义技能**：部分怪物拥有独特技能（治疗、分裂、传送、眩晕、闪避…）

### 💰 经济

- 每 **6 秒**获得一次金币，数量等于你的**收入**
- 送怪和击杀怪物都能提高收入；进攻者同样吃被动收入
- 放置塔和送怪都要消耗金币——平衡好进攻与防守

### ❤️ 生命与胜利

- **经典模式**：你的怪走到对方赛道终点 → 偷走对方 1 心（死亡骑士偷 2 心）
- **围攻模式**：进攻者的怪突破防线 → 扣防守者 1 心；守住 10 分钟即胜
- **合作模式**：漏怪只扣自己 1 心，打完 20 波全员胜利

## ✅ 技巧与策略

- **管理经济**：前期别乱花——确保有足够金币布置防线
- **组合技能**：把能力互补的塔搭配起来（减速+溅射、激光+狙击）
- **针对敌方塔**：侦察对手用了什么塔，再针对性出兵
- **围攻进攻者**：低费怪消耗 + 高费怪突破，配合召唤进化专精一路
- **合作防守**：优先守住被系统选中的赛道，波次间隙补塔
